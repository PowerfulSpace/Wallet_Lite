# PS.Wallet Frontend

Vue 3 + TypeScript + Vite frontend scaffold for the Wallet API.

**Status:** Scaffold only. Backend-first development. See `docs/frontend/overview.md`.

## Development

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173 and proxies /api to the backend at http://localhost:5254.

## Build

```bash
npm run build
npm run lint
```
